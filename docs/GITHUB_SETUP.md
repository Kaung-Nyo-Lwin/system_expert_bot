## Remove the fork relationship

The “forked from” label is GitHub repository metadata. Editing the README, removing a local remote, or rewriting commits does not remove it.

GitHub provides a **Leave fork network** action for a public fork smaller than 1 GB with no child forks. This repository met those conditions when inspected for the portfolio refresh.

1. Open [repository settings](https://github.com/Kaung-Nyo-Lwin/system_expert_bot/settings).
2. In **General → Danger Zone**, choose **Leave fork network**.
3. Read the effects, confirm the repository name, and complete the action.

Detachment is permanent, preserves Git commit metadata, and does not preserve repository metadata such as stars, issues, pull requests, and watchers. Review the current state before proceeding. The initial inspection found no stars, open issues, or child forks.

Use the supported settings action; deleting this repository or rewriting contributor history is unnecessary. The maintained portfolio edition still acknowledges the original team project.

Source: [GitHub's detaching a fork guide](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/detaching-a-fork).
